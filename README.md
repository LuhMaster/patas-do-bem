# 🐾 Patas do Bem

## Sobre o projeto

O **Patas do Bem** é uma aplicação web responsiva desenvolvida com o objetivo de facilitar a divulgação e a consulta de animais perdidos, encontrados e disponíveis para adoção.

O projeto foi pensado para apoiar associações de proteção animal e voluntários, ajudando a organizar as informações dos animais e ampliar suas chances de encontrar seus tutores ou um novo lar.

Esta versão corresponde ao protótipo frontend do projeto, desenvolvido como parte de um trabalho acadêmico de desenvolvimento de software.

## Funcionalidades

- **Consulta pública:** visualização dos animais cadastrados.
- **Busca e filtros:** pesquisa por nome, localização e situação do animal.
- **Detalhes do animal:** visualização de informações adicionais sobre cada caso.
- **Login de voluntário:** acesso simulado à área de gerenciamento.
- **Cadastro de animais:** registro de informações, características e fotografias.
- **Gerenciamento:** opções de edição e exclusão dos registros.
- **Layout responsivo:** adaptação da interface para computadores e dispositivos móveis.

## Tecnologias utilizadas

- **Angular:** desenvolvimento da interface e organização dos componentes.
- **TypeScript:** implementação da lógica da aplicação.
- **HTML:** estruturação das páginas.
- **CSS:** estilização e adaptação responsiva.

## Como executar o projeto

### Pré-requisitos

- [Node.js](https://nodejs.org/)
- npm (instalado junto com o Node.js)
- [Angular CLI](https://angular.dev/tools/cli)

### Instalação

1. Clone o repositório:

   ```bash
   git clone URL_DO_REPOSITORIO
   ```

2. Entre na pasta do projeto:

   ```bash
   cd patas-do-bem
   ```

3. Instale as dependências:

   ```bash
   npm install
   ```

4. Inicie a aplicação:

   ```bash
   ng serve --open
   ```

5. A aplicação será disponibilizada em:

   `http://localhost:4200/`

   Link de visualização na vercel:
   https://patas-do-bem-pink.vercel.app/

## Observações

Esta versão é um protótipo frontend. O login é simulado e os dados dos animais não possuem persistência em banco de dados nesta versão.

A integração com o backend e a implementação da persistência de dados fazem parte de uma etapa posterior do desenvolvimento.

## Objetivo do projeto

Contribuir para a proteção animal por meio da tecnologia, oferecendo uma ferramenta simples e acessível que auxilie voluntários na divulgação e organização de casos de animais perdidos, encontrados e disponíveis para adoção.
